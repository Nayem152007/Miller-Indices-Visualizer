📚 About Miller Indices

Miller indices are a system of notation used to describe the orientation of crystallographic planes within a crystal lattice.

They are written as:

(h k l)

The indices are obtained from the reciprocals of the fractional intercepts of a plane with the crystallographic axes, followed by clearing fractions when necessary.

For example, a plane with intercepts:

a, b, ∞

has Miller indices:

(1 1 0)

This visualizer provides an interactive 3D way to understand how different Miller indices correspond to different crystallographic planes.

🎓 Purpose

This project was created as a crystallography learning tool to make Miller indices easier to visualize and understand.

Rather than relying only on 2D textbook diagrams, users can interact with the 3D coordinate system and observe the orientation of different crystallographic planes.
